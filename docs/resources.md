# Research and references

| Apple · [JSONDecoder](https://developer.apple.com/documentation/foundation/jsondecoder)                                                                        | Nikita’s walkthrough: reading landmark records from bundled JSON.                                                        |
| Apple · [List](https://developer.apple.com/documentation/swiftui/list)                                                                                         | Nikita’s walkthrough: displaying one row per place.                                                                      |
| Apple · [NavigationLink](https://developer.apple.com/documentation/swiftui/navigationlink)                                                                     | Nikita’s walkthrough: opening the details of the selected landmark.                                                      |
| Apple · [Image](https://developer.apple.com/documentation/swiftui/image)                                                                                       | Nikita’s walkthrough: looking up the photograph named by the record’s `imageName`.                                       |
