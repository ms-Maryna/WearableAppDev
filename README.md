## About the Project

This repository holds the research, presentation materials and live demo for our group presentation
on **Wearable App Development**.

We look at how apps are built for wearable devices (smartwatches, fitness trackers and similar),
which platforms and SDKs exist, how wearable apps talk to a paired phone, and which design and
technical limits developers face on small, battery-powered devices.

As well as researching the topic, we build and run a small demo app so we can show we have used the
technology in practice.

## Assignment Requirements

The full brief is in [`docs/`](docs/).

Our group researches the assigned topic and presents what we found in a presentation of up to 20
minutes, using PowerPoint and/or other presentation tools. The presentation includes a live demo of
the technology, such as setting up the SDK and building or running a demo app, to show we have
worked with it in practice. The research is backed by at least 8 relevant sources, listed on a
References slide at the end. After the presentation we answer questions from the class and lecturer
in a Q&A session.

### Deliverables

We deliver the presentation to the class group and the lecturer, run a live demo of the practical
part, and answer questions in the Q&A session. We also prepare a pre-recorded screencast of the
demo, which can be shown instead of the live demo if there are technical problems. The PowerPoint
slides, with a References page at the end, are uploaded to Moodle together with the rest of the
material.

Grading criteria are in [`docs/requirements.md`](docs/requirements.md), and the draft presentation
plan is in [`docs/presentation-outline.md`](docs/presentation-outline.md).
